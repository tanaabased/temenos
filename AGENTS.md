# Temenos workspace

This scaffold is for contributors, not for running an agent. Read
[IDENTITY.md](IDENTITY.md) for agreed identity metadata,
[SOUL.md](SOUL.md) for open mission and boundary decisions, and the
[voice draft](skills/voice/SKILL.md) for editorial context. The
[local skill standard](references/skill-standard.md) governs Temenos skills.

Use Bun, ESLint, and standalone Prettier. Run the checks in
[README.md](README.md#development) before proposing changes.

Keep credentials, logs, private context, and runtime state out of the repository.
Do not connect accounts, configure deployment, or activate automations as part
of scaffold work.
